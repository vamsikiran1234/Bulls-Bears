## 🚀 Rapid Quick Start Guide

### Prerequisites
* **Python**: `3.11+`
* **Node.js**: `18.0+` & `npm`

### Step 1: Launch Backend Server
```bash
# Navigate to the backend directory
cd backend

# Create & activate a Python virtual environment
python -m venv .venv
source .venv/bin/activate       # macOS / Linux
.venv\Scripts\activate          # Windows PowerShell

# Install required Python packages
pip install fastapi uvicorn sqlalchemy aiosqlite pydantic pydantic-settings python-jose passlib bcrypt pytest httpx

# Start the async FastAPI server with hot-reload
uvicorn app.main:app --reload --port 8000
```
> [!NOTE]
> The backend automatically initializes `bulls_bears.db` and seeds the 13 trading achievements on startup.  
> Interactive OpenAPI documentation is accessible at **`http://localhost:8000/docs`**.

### Step 2: Launch Frontend Client
Open a second terminal window:
```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Start Vite development server
npm run dev
```
> [!TIP]
> Open your browser at **`http://localhost:5173`** to enter the live Bulls & Bears trading arena!

## 🛡️ Security & Fair Play Guarantee

* **Zero Client-Side Leaks**: The target word is strictly encrypted server-side and never returned over HTTP until the game reaches a terminal status (`won` or `lost`).
* **Server-Side Validation**: All moves are verified against the canonical server dictionary (`backend/app/data/words_valid.txt`).
* **Tamper-Resistant Scoring**: Score calculations, speed bonuses, and win streaks are validated server-side by the scoring engine.
